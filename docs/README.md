# Cellulary documentation

| Guide | Use it to |
| --- | --- |
| [Compatibility](compatibility.md) | Choose a module and understand the support level of each feature |
| [Hardware and command reference](hardware-support.md) | Check official sources, firmware differences and AT command semantics |
| [Architecture](architecture.md) | Understand the layers and implement a vendor/model driver |

| [Hardware validation](hardware-validation.md) | Review dated, sanitized observations from physical devices |
| [Vendor source manifest](vendor-sources.json) | Find original URLs, versions, dates and SHA-256 checksums |

Start with the [quick start](../README.md#quick-start). For API schemas, start `cellulary web` and visit `http://127.0.0.1:8765/docs`. For the CLI, use `cellulary --help` and the help for each subcommand.

English is the default documentation language. Each prose guide has a linked Chinese companion under `docs/zh-CN/`. Vendor files remain in their original language and are excluded from version control.
