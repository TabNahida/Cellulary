## 平台范围

Python 包需要 Python 3.11 或更新版本，通过 pyserial 访问串口。目前真机验证与主机网络管理面向 Windows；其他系统需要适当的权限、驱动及网络集成。能枚举串口不等于已经验证跨平台功能。

自动发现选择已识别的移远 AT 接口。多个产品可能共用 VID/PID，一个模块也可能有多个端口，因此驱动选择还需厂商、型号与固件信息。未知设备的能力应明确保持未知。

## 固件差异

EC801E 与 EC200A 的命令不能完全互换。EC801E 官方手册限制短信、字符集等命令，实际固件也可能晚于手册。应检测相关能力并保留不可用原因，不能把未插 SIM 变成永久的硬件不兼容结论。

`CNUM` 读取 SIM 中的本机号码记录。成功但为空，表示 SIM 没有提供号码，不是网络故障。电话本回退是可选操作，不应改写 SIM 记录。

AT 命令成功只能确认模块响应，不能证明短信送达、通话声音、GNSS 定位或电脑上网。应用分别展示这些结果。

## 资料状态

本地已取得 **15 份移远官方 PDF**，包括 A/E AT、USB 描述符、硬件、PPP、音频、UAC 和 IMS 资料。文件从移远中国官网下载，[vendor-sources.json](../vendor-sources.json) 记录来源、版本和校验值。原件位于被 Git 忽略的 `docs/vendor/`，不随软件再分发。

[命令依据](hardware-support.md) 列出实现所用章节。资料已下载不代表全部功能适用于每个模块，尤其是 E 系列音频指导的适用表并不包含 EC801E。

## 新增型号

添加厂商/型号驱动、命令及解析测试、资料依据和带日期的真机记录。在取得证据前，能力应保持未知或不支持。新增 5G 模块需要单独处理 USB 接口布局、网络注册字段、数据模式及语音支持。
